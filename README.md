# Vườn Đậu Pixel

Bảng xem animation pixel art của các cây bắn và đạn theo phong cách Plants vs. Zombies,
dựng bằng Aseprite ở độ phân giải pixel thật.

Trang: https://thucnc7.github.io/pvz-pixel-garden/

`index.html` tự chứa — mọi GIF đã nhúng thành data URI, mở trực tiếp bằng trình duyệt
là chạy, không cần server hay file kèm.
